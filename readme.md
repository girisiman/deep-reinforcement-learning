# deep-rl

This repo is my study log for deep reinforcement learning: lecture notes, course assignments, and experiments from the courses I am working through. The goal is a working understanding of the algorithms, not a solution dump, so writeups and results live next to the code that produced them.

## Layout

- `notes/` — weekly notes, written by me
- `courses/cs224r/` — Stanford CS224R (Chelsea Finn). `hw1/` is imitation learning.

## Setup

Python 3.10, CPU PyTorch. Each homework has its own environment notes under `courses/cs224r/hwN/`. This machine has no GPU.
